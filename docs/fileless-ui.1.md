# fileless-ui(1)

`fileless-ui` is the unprivileged GNOME and KDE Plasma indicator and alert window. Add the desktop user to `filelessd-ui`, then log out and back in. It displays High and Medium alerts but sends native notifications only for High alerts.

On GNOME, use the standard AppIndicator extension supplied by the distribution. KDE Plasma uses its built-in StatusNotifier support. No custom desktop extension is included.
